# hwpPzWall

한글(HWP) 프레젠테이션 중 화면 가장자리에 마우스가 닿아 **쪽 미리보기 창이 튀어나오는 것**을 막는 Windows 트레이 앱입니다.

한글에는 이 창을 끄는 설정이 없어서, 한글 바깥에서 마우스가 그 자리에 **닿지 못하게** 만드는 방식으로 해결합니다.

---

## 어떻게 막는가

저수준 마우스 훅(`WH_MOUSE_LL`)으로, 커서가 금지 영역에 들어오는 이동 이벤트를 **한글에 전달되기 전에** 가로챕니다.

동작 방식은 두 가지 중에 고를 수 있습니다.

| 모드 | 동작 | 모니터 간 이동 |
|---|---|---|
| **뛰어넘기** (기본) | 진행 방향으로 금지 영역 **반대편에** 커서를 다시 놓아, 그 띠를 건너뛰게 한다 | 그대로 됨 |
| **완전 차단** | 벽처럼 막아 그 방향으로 더 못 가게 한다 | 그 방향으로는 막힘 |

### 빠른 마우스 이동에 대하여

마우스 하드웨어는 절대 좌표가 아니라 **이동량**을 보내고, Windows 는 여기에 **포인터 가속**을 적용합니다. 빠르게 움직여도 보고 횟수(125~1000Hz)는 그대로이고 **한 번에 건너뛰는 거리만 커집니다.**

```
천천히:  … 62 → 60 → 58 → 56 …      (2px 씩)
빠르게:  … 200 → 120 → 40 → -50     (80px 씩 — 중간 좌표는 존재하지 않음)
```

그래서 도착 좌표만 검사하면 좁은 띠는 그대로 넘어가 버립니다.

- **뛰어넘기 모드**에서는 문제가 아닙니다. 커서가 띠 안에 머문 적이 없으니 목적은 달성된 것입니다.
- **완전 차단 모드**에서는 벽이 뚫리므로, 점이 아니라 **이동 경로(선분)가 띠를 가로지르는지**로 판정합니다 (`ZoneGeometry.CrossesAnyZone`). 빠르게 움직여도 뚫리지 않습니다.

기본값인 **뛰어넘기**를 쓰면, 발표 모니터가 주 모니터 오른쪽에 있어도 마우스는 평소처럼 두 화면을 오갑니다. 다만 왼쪽 끝 몇 픽셀에는 **한 번도 머무르지 않으므로** 한글이 미리보기를 띄울 계기 자체가 없습니다.

> AutoHotkey 로 흔히 쓰는 `ClipCursor` 방식은 커서를 한 사각형 **안에 가두는** 것이라, 켜 두면 다른 모니터로 아예 못 넘어갑니다. 이 앱이 그보다 나은 지점입니다.

## 쓰는 법

1. `dist\hwpPzWall.exe` 실행 (설치 과정 없음, .NET 설치도 불필요)
2. 처음 실행하면 설정창이 뜹니다.
   - **모니터**: 발표용 모니터를 고릅니다. 드롭다운에서 고르거나, **아래 미리보기에서 모니터 그림을 직접 클릭**해도 됩니다. 어느 게 몇 번인지 헷갈리면 **[번호 확인]** 버튼을 누르면 각 화면에 번호가 잠깐 표시됩니다.
   - **가장자리**: 막을 변에 체크하고 폭(px)을 정합니다. 한글 미리보기는 보통 **왼쪽 10~30px** 안에서 열립니다. 기본 15px 로 시작해서, 그래도 뜨면 20~30 으로 늘리세요.
   - **[영역 확인]**: 지정한 영역을 실제 화면 위에 **반투명 붉은 박스**로 띄웁니다. 켜 둔 채로 px 값을 바꾸면 박스가 바로 따라 움직이니, 눈으로 보면서 폭을 맞추면 됩니다. 박스는 클릭이 통과하므로 뒤쪽 작업을 막지 않습니다.
   - **단축키**: 입력칸을 클릭하고 원하는 키를 누릅니다. 기본값 `Ctrl + Alt + F9`. F1~F12 는 단독으로도 지정할 수 있습니다.
3. 저장하면 트레이에 상주하고, **처음 설정한 직후에는 차단이 자동으로 켜집니다.** 이후에는 단축키나 트레이 우클릭 메뉴로 켜고 끕니다.

## 지금 켜져 있는지 확인하는 법

세 군데에서 확인할 수 있습니다.

- **트레이 아이콘 색** — **붉은색이면 차단 중**, 회색이면 꺼짐. 색뿐 아니라 화면 안쪽 색조까지 함께 바뀌어서 16px 크기에서도 구분됩니다.
- **아이콘에 마우스를 올리면** 나오는 풍선 — `hwpPzWall — 차단 켜짐 (Ctrl + Alt + F9)`
- **설정창 맨 위 상태 줄** — 현재 켜짐/꺼짐과 켜는 방법이 적혀 있습니다.

> **아이콘이 안 보인다면** 숨겨진 영역에 들어가 있는 것입니다. 작업 표시줄의 `^`(숨겨진 아이콘 표시)를 눌러 hwpPzWall 아이콘을 **작업 표시줄 쪽으로 끌어다 놓으면** 항상 보입니다. 발표 중에 상태를 바로 확인하려면 이렇게 고정해 두는 편이 좋습니다.

### 트레이 메뉴

- **차단 켜기 / 끄기** — 단축키와 같은 동작
- **설정...** — 아이콘을 더블클릭해도 열립니다
- **Windows 시작 시 자동 실행**
- **종료**

## 알아둘 점

- **UAC**: 이 앱은 일반 권한으로 실행됩니다. 관리자 권한으로 실행 중인 프로그램의 창 위에서는 Windows 정책(UIPI)상 마우스 이벤트를 가로챌 수 없습니다. 한글은 보통 일반 권한이라 문제되지 않지만, 혹시 안 먹으면 이 앱도 관리자 권한으로 실행해 보세요.
- **모니터 구성 변경**: 해상도나 모니터 배치가 바뀌면 자동으로 영역을 다시 계산합니다. 설정은 장치 이름 → 좌표 → 번호 순으로 모니터를 찾으므로, 케이블을 바꿔 꽂아도 대체로 유지됩니다.
- **설정 파일**: `%APPDATA%\hwpPzWall\config.json`
- **로그**: `%APPDATA%\hwpPzWall\hwpPzWall.log` (문제 생겼을 때만 보면 됩니다)
- 앱을 종료하면 훅도 반드시 해제되므로 마우스가 막힌 채로 남지 않습니다.

## 직접 빌드하기

.NET 8 SDK 필요.

```powershell
# 개발용 빌드 + 실행
dotnet run --project "src\hwpPzWall"

# 좌표 계산 검증 (실제 마우스·화면 없이 돌아감)
dotnet run --project "tests\GeometryTests"

# 배포용 단일 exe
dotnet publish "src\hwpPzWall" -c Release -o dist
```

아이콘 그림을 바꾸려면 `src\hwpPzWall\IconFactory.cs`(트레이용)와 `build-icon.ps1`(exe 아이콘)을 함께 고치고, 후자를 실행해 `app.ico` 를 다시 만듭니다.

## 구성

```
src\hwpPzWall\
  Program.cs           진입점, 중복 실행 방지
  TrayApp.cs           트레이 아이콘 · 메뉴 · 상태 관리
  SettingsForm.cs      설정 화면
  PreviewPanel.cs      모니터 배치 미리보기 (클릭해서 모니터 선택)
  MonitorIdentifier.cs [번호 확인] 오버레이
  ZoneOverlay.cs       [영역 확인] 반투명 붉은 박스 (클릭 통과)
  Hotkey.cs            단축키 입력칸, 전역 단축키 · 디스플레이 변경 수신 창
  BlockEngine.cs       마우스 훅 설치와 적용
  ZoneGeometry.cs      좌표 계산 (순수 함수, 테스트 대상)
  AppConfig.cs         설정 저장 · 모니터 매칭 · 금지 사각형 생성
  MonitorInfo.cs       모니터 열거 (물리 픽셀)
  AutoStart.cs         시작 프로그램 등록
  IconFactory.cs       트레이 아이콘 그리기
  Native.cs            Win32 P/Invoke
tests\GeometryTests\   좌표 계산 검증 35종 (빠른 이동 경로 판정 포함)
```

좌표는 전부 **물리 픽셀** 기준입니다. 앱이 Per-Monitor V2 DPI 인식으로 동작하므로 모니터마다 배율이 달라도 좌표가 어긋나지 않습니다.
